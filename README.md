# SAFEHX-PIDDec

Code and data for the paper:

> A. Rossi, C. Garcia. *Cross-coupling compensation with a standard PID block tuned by Response Surface Methodology: application to a strongly coupled heat exchanger.* Submitted to the Journal of Process Control.

A standard two-degree-of-freedom PID function block (Siemens `PID_Compact`) is used as a cross-coupling compensator (**PIDDec**) for the strongly coupled pressure–flow loops of a 100 kW SAFEHX® pilot heat exchanger. Its six parameters are tuned by sequential Response Surface Methodology (RSM), without model inversion, and the method is also applied to two benchmark processes from the literature (Hylte pulp flow process and Wood–Berry column).

Every result, table and figure of the paper is generated by the Python code in this repository.

## Quick start

Requires Python 3.9 or newer.

```bash
git clone https://github.com/alexandre-rossi/SAFEHX-PIDDec.git
cd SAFEHX-PIDDec
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
bash run_all.sh                  # Windows: run "python make_figures.py" and "python gen_macros.py"
```

`run_all.sh` regenerates all figures (`figures/`) and the file `results/results_macros.tex`, which contains every number quoted in the paper, from the stored optimization results (about one minute). To rerun all optimizations from scratch first, use `bash run_all.sh --full` (about 30 minutes).

## Repository structure

| Path | Content |
|---|---|
| `data/` | Open-loop identification experiments (valve and pump PRBS excitations), sampled at 0.1 s |
| `identification/` | GNU Octave scripts used to identify the plant model (Section 2.2 of the paper) |
| `safehx/model.py` | Identified plant, `PID_Compact` 2-DoF controllers and closed-loop state-space model |
| `safehx/rsm.py` | Sequential RSM: coded variables, factorial / Box–Behnken designs, Ridge regression with leave-one-out, L-BFGS-B, adaptive region |
| `safehx/baselines.py` | Ideal, filtered ideal and static decouplers; perturbed plants for the Monte Carlo analysis |
| `safehx/benchplants.py` | Benchmark processes (Hylte, Wood–Berry) and the IAE criterion |
| `safehx/loadsim.py`, `safehx/metrics.py` | Load-disturbance simulation and performance indices |
| `run_rsm_iae.py`, `run_rsm_iae_static_init.py` | RSM tuning of the PIDDec for the heat exchanger |
| `benchmarks2.py`, `optimize_static.py`, `load_disturbance_benchmarks.py` | Benchmark processes, two-way decoupling |
| `make_figures.py`, `gen_macros.py` | All figures and tables of the paper |
| `results/` | Stored optimization histories and result tables |
| `figures/` | Figures of the paper (PDF and PNG) |
| `paper/` | TikZ source of the block diagram |
| `legacy/` | Scilab/Xcos and Python scripts of the first version of the study (superseded by the Python pipeline) |

## Model

The plant model (Eq. 2 of the paper) was identified in GNU Octave from the data in `data/`, with the MataveID toolbox (pump excitation) and the SLICOT `moen4` subspace method (valve excitation). The coefficients are stored in `safehx/model.py`.
